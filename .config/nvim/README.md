# my-nvim-config

My neovim configs including my personal tmux replacement via neovim.

Telescope and fzf-lua are disabled by default. Enable both for a session with:

```sh
env NEOVIM_EXTRA_PICKERS=1 nvim
```

Their installed copies are retained while disabled.
